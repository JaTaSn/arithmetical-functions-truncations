  n=1: Gamma_1 = K (r=0). Trivially Gorenstein; degenerate, m = 0.
  n=2: S = Multivariate Polynomial Ring in x over Rational Field, minbase(I_2) = [x^2]
       so Gamma_2 = K[x]/(x^2), a hypersurface, hence a complete
       intersection, hence Gorenstein.
  n=3: minbase(I_3) = [x1^2, x0*x1, x0^2], so Gamma_3 = K[x,y]/(x,y)^2, type 2.

  Cross-check independent of the socle count, via Avramov's remark
  after 5.2.5 in *Infinite free resolutions* (a Golod Gorenstein local
  ring is a hypersurface): Gamma_n is Golod for every n, so it is
  Gorenstein only if mu(I_n) = C_n <= 1.
