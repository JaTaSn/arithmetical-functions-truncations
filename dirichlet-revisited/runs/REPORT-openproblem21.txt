STAGE model -- exact S_2(n) against the smooth model Q(n)
========================================================================================================

  Q(n) = int_2^{sqrt n} (Li(t)-1)(Li(n/t)-Li(t)+1) dt/log t,  Li = offset li.
  Q is the integral the derivation evaluates; the derivation says
  Q(n) ~ (16/3) n^{3/2}/log^3 n, and this stage asks how fast Q(n) ~ S_2(n).

  Two intermediate quantities isolate the two approximations Q makes:
    E(n) = sum_{p <= sqrt n} (pi(p)-1)(Li(n/p) - pi(p) + 1)   [only the inner pi -> Li]
    D(n) = sum_{p <= sqrt n} (Li(p)-1)(Li(n/p) - Li(p) + 1)   [both pi -> Li]
  so S_2 -> E -> D -> Q replaces pi by Li, then the sum over primes by dt/log t.
